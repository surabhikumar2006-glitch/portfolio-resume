# Surabhi K | Portfolio

Personal portfolio website for Surabhi K, Computer Science and Engineering student.

Single-page site built with HTML, Tailwind CSS (CDN) and Alpine.js (CDN). No build step: open `index.html` in a browser.

## Sections
Skills, Selected work, About (education and interests), Contact.
